# Tableau des Charges Horaires - Conception des Ressources

> **Formule** : `Vhtc = Vhn x S`
> - **Vhtc** : Volume Horaire Total pour la Conception
> - **Vhn** : Volume Horaire pour la conception des ressources selon le niveau de complexité
> - **S** : Nombre de séances

> ⚠️ **Note** : Le volume pour la mise à jour de cours est la moitié du volume horaire pour la conception.
